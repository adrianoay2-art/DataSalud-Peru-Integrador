# DataSalud-Peru-Integrador 🏥📊

Repositorio oficial que consolida los componentes técnicos del proyecto integrador orientado al análisis de datos de salud, construcción de Data Warehouse, modelado dimensional y Business Intelligence.

---

## 📂 Estructura del Repositorio (Bloques Temáticos)

El repositorio se encuentra organizado por bloques temáticos para separar las responsabilidades del sistema:

```text
DataSalud-Peru-Integrador/
│
├── Data/raw/               # [Datos Externos] Contiene el archivo README o acceso con el enlace de Google Drive a los datasets pesados.
├── database/               # [Seguridad y Modelado SQL] Scripts DDL, creación de tablas, roles y store procedures en SQL Server.
├── notebooks_bigdata/      # [BigData y Automatización] Scripts de Python / Pandas para procesos ETL y procesamiento masivo.
└── README.md               # Documentación general y guía del proyecto.
